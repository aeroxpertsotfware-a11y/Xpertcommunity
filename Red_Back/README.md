# API de Red Drones

Base de la API que conectará la aplicación móvil con MongoDB. La app nunca debe contener la URI ni las credenciales de la base de datos.

1. Reemplaza los valores de ejemplo en `.env` por los datos reales de MongoDB.
2. Ejecuta `npm install` y después `npm run dev`.
3. Comprueba `GET http://localhost:4000/health`.

La API no incluye aún cuentas, publicaciones ni anuncios. Esos módulos se añadirán cuando definamos las pantallas y reglas de cada función.
